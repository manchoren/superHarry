## Host and choices

The current Windows process reports `AMD64`; a read-only WSL distribution listing shows only `docker-desktop`. Do not modify that distribution. These observations are not a compatibility, feature-availability, or performance test.

A fresh Linux VM on Windows x64 running QEMU TCG is another host variant of the Linux options, with additional hypervisor, OS and nested-operation review; no specific verified product/version is selected here. Microsoft says [Hyper-V on an x64-based Windows device does not support Arm64 VMs](https://learn.microsoft.com/en-us/windows/arm/iso); that statement concerns Windows Arm64 VMs, and it does not provide evidence for running an ARM64 Linux system directly. Do not treat Hyper-V alone as established cross-architecture emulation on this host. Docker's [multi-platform build documentation](https://docs.docker.com/build/building/multi-platform/) describes user-space emulation via QEMU and binfmt, not a booted ARM64 OS or Pi-equivalent kernel; it is not evidence that full ARM64 environment, system services or required integration tests work. No Docker/container dependency, privileged operation or reuse of `docker-desktop` is authorized by this document.

## Decision and verification

None of the candidates has a complete security or license disposition, tested boot, or owner approval. Before asking for selection, identify exact source and binary digests, provenance and licenses for host OS/WSL, emulator, transitive dependencies and firmware; review actual applicable CVEs and device graph; specify storage, networking, guest image, disposable credentials, update/snapshot policy and recovery. G-ARCH and G-OPS apply before provisioning. No selected option bypasses the sandbox or package-guard requirements for superHarry runtime operations.

A future approved smoke test should boot the authenticated Debian ARM64 image, verify architecture and process startup with synthetic data, and record versions, device model and all environment changes. Emulated ARM64 does not establish Raspberry Pi hardware performance, thermal behavior, HDMI, GPU, physical isolation or production sandbox effectiveness. No installations, executions, tests or hardware claims were made in this research.
