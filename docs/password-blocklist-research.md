# Local password blocklist research

Status: research only, 2026-10-30; no corpus, downloader, dependency or update process selected or approved. Constitution baseline 2026-10-29, SHA-256 `426923873e828b7a0e8fd63b88a5a9b5e01b35f9c2e3bb965c322931d1d9835a`. Tasks T007, T014 and T026; see [security decisions](security-open-decisions.md). The accepted policy compares complete normalized prospective passwords locally, and blocks password creation or changes if the required list is unavailable; existing logins remain available.

## Design constraints and next evidence

[NIST SP 800-63B](https://pages.nist.gov/800-63-4/sp800-63b.html) specifies whole-password blocklist comparison and notes that size should be appropriate to throttling; it does not validate either candidate for this application. HIBP's published SHA-1 values are lookup identifiers, not an approved substitute for Argon2id password storage. Evaluate whether normalization of input matches the corpus and document any missed equivalent encodings; preserve Unicode and do not log a candidate, its hash or selected values. Include context-specific words under a separately reviewed policy. Imported data and downloaded files must never be committed as secrets or personal data.

Before requesting a selection, verify dataset-specific terms and provenance, pin an exact release or acquisition date and integrity method, determine actual size and update cost, and review ARM64 storage, lookup latency and failure behavior. Define authenticated staging, atomic promotion, recovery, bounded disk usage and offline behavior; ensure missing, corrupt or incomplete data blocks password creation/change while existing login remains possible. Protect access to the corpus and update artifacts. No API calls involving candidate passwords are authorized by this research. Synthetic tests should cover normalized whole-value matching, corrupt and partial datasets, rollback, stale updates and no credential logging. Real Pi measurements and exact dependency approval remain separate gates.

No corpus was downloaded, software installed, performance measured or legal conclusion asserted.
