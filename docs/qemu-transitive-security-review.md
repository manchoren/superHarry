## Required next evidence

1. Authenticate and retain a consistent repository index and trusted keys; retrieve and verify each exact artifact and source recipe, including its downstream patch set. Re-evaluate if a package version or digest changes.
2. Enumerate current upstream, vendor and applicable security advisories for **every** selected package, not only the examples above; record affected/fixed ranges, exact patch evidence, configuration and reachable attack surfaces. Mandatory unresolved checks block selection/installation; no compensating control is assumed accepted.
3. Review the complete realized dependency and device graph, host network boundaries, guest-controlled inputs and library loading under the separately approved environment. Execute tests only after relevant dependency and operations approvals. An omitted device or unused library cannot be assumed without validating the actual build and configuration.
4. Review all package licenses, notices, signature chains and support status alongside advisories. The advisory research did not install or execute QEMU or any candidate package and did not validate ARM64 guest boot.
